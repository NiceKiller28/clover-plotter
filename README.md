# Clover Plotter

Рукописный плоттер для 3D-принтера: ручка вместо сопла пишет ваш текст почерком, как от руки — с формулами, таблицами, рисунками и вашим собственным почерком. Бесплатно, для Windows.

**Сайт:** https://nicekiller28.github.io/clover-plotter/

**Скачать:** [Clover-Plotter.exe](https://github.com/NiceKiller28/clover-plotter/releases/latest/download/Clover-Plotter.exe) — один файл, без установки.

Все приложения семьи — в [Clover Store](https://nicekiller28.github.io/).

## Версия 1.5.0

Новое меню «Студия»: «Как пишет перо» — анимация письма в темпе принтера; «Дописать по фото листа» — продолжение начатой страницы по линовке; «Цвета и ручки» — цвет в тексте и G-code по ручкам; «Перо-арт» — спирограф, узоры, гравюра и портрет одной линией.

## Версия 1.4.1

Без проверки активации — программа бесплатная. «Перевернуть лист», разворот на две страницы, редактор таблиц и таблица из буфера, люфт по X/Y, «Уменьшить движение». Проекты сохраняются как .clover, старые файлы открываются как раньше.

## Версия 1.4.0

Оформление прежнее, новый движок письма: связки как в прописях, «живой почерк», ошибки как у людей, формулы выбранным шрифтом. Новый редактор почерка с почерком по фотографии. Меню «Устройство»: печать напрямую на принтер (Marlin по USB, Bambu Lab A1 / A1 mini по сети) и XY-плоттер GRBL. Проекты, 67 профилей принтеров с выбором по производителю, белорусский и башкирский языки, растягиваемые панели, обучение при первом запуске и автообновление.

## Версия 1.2.2

Исправлен запуск с сохранённым принтером Anycubic Kobra S1. В сборку включены недостающие подготовленные профили принтеров. Текст, остальные настройки и сохранённые калибровки не сбрасываются. Если сохранённый профиль отсутствует, программа открывается с предупреждением и сохраняет копию исходных настроек.
